# Engine notes: Indian Rummy (13-card)

Seats 0..n-1 (default 2, support 2–6). Two standard decks + 2 printed jokers (X1, X2 — since there are 2 copies of each card, cards are identified by code and duplicates are interchangeable). Setup: shuffle, deal 13 each, turn up the wild-joker card (cut joker; if it is a printed joker, Aces are wild), first discard card face-up, rest = closed stock. Moves: {type:'draw', from:'stock'|'discard'}, then {type:'discard', card} OR {type:'declare', discard: card} (declare = discard that card and show a valid 13-card hand), {type:'drop'} only BEFORE drawing on your turn (first drop if you have not drawn yet this game = 20 points, middle drop = 40). A player may not take the wild-joker indicator; jokers in the discard pile may be picked (standard rule: allowed). If the stock runs out, reshuffle the discard pile except its top card (use rngState). Validation: export melds.ts with a FAST exact solver bestArrangement(hand: CardCode[], wildRank: Rank | 'A-if-printed'...) → { groups: { kind: 'pure-sequence'|'sequence'|'set'|'unmatched', cards }[], valid: boolean (≥ 2 sequences incl ≥ 1 pure, all 13 cards grouped), deadwoodPoints (min points of ungrouped cards respecting the 'no pure sequence → count all' rule, capped at 80) }. It must handle jokers substituting in sets/sequences, Ace low (A-2-3) or high (Q-K-A) but no wrap, sets of 3–4 distinct suits, sequences of any length ≥ 3, duplicates from two decks, and run in a few ms (memoise / prune; the bot calls it often). Declaring with an invalid hand is ILLEGAL (checkMove explains exactly what's missing, e.g. 'You need at least one pure sequence — a run of 3+ cards in one suit with no jokers.'). On a valid declare the declarer wins and each other player pays min(80, their deadwood); with 2 players humanNetUnits = +opponent points if the learner wins, −own points if the learner loses (more players: learner wins sum of others' points; loses own points). Drop: the dropper pays 20/40 and (2 players) the other wins. Bots: normal draws from discard only if that card improves its arrangement, discards the card that minimises deadwood (prefer high unconnected cards, keep jokers), declares when valid, drops a hopeless starting hand rarely; easy is a simpler greedy. Bots never see others' hands or the stock order. Cap: if 200 turns pass with no declaration (can happen with weak bots), end with every player scored by deadwood and the lowest wins (document it). Flags: perfect when declaring with 0 jokers used or within 3 turns; comeback when the learner's deadwood was ≥ 60 at some point and they still won; closeFinish when the loser's points ≤ 10; bigPot when |net| ≥ 40; folded when the learner drops. Content: order 120, featured true. Teach sets, sequences, pure sequence, wild joker, printed joker, declare, drop, deadwood clearly with scenes.
