# Engine notes: Teen Patti

Seats 0..n-1, default 3. State tracks each player's chips contributed, blind/seen status, packed status, the current stake (blind-equivalent, starts at 1 boot), pot, turn order (dealer chosen by seed, play starts left of dealer). Moves: {type:'see'} (blind → seen; same player then acts again), {type:'pack'}, {type:'chaal'} (blind pays stake, seen pays 2×stake), {type:'raise'} (blind pays 2×stake and stake doubles; seen pays 4×stake and stake doubles) only if the new stake ≤ 8 boots, {type:'show'} only when exactly 2 players remain (costs a chaal; then compare; equal hands → the asker loses). Pot limit 64 boots: if a bet would push the pot to ≥ 64, cap it and go to a show between all remaining players (best hand wins; equal best → split). Last player standing wins the pot. Export a hand evaluator (hand-eval.ts: rankHand(cards) → { category: 'trail'|'pure-sequence'|'sequence'|'colour'|'pair'|'high-card', values: number[] , name: 'Trail of Kings' etc. }, compareHands). Sequences: A-K-Q highest, A-2-3 second, then K-Q-J … 4-3-2. Units: 1 unit = 1 boot; humanNetUnits = chips won − chips contributed (in boots); maxLossUnits 64. Bots: normal plays blind for a round or two then sees, evaluates hand strength (and pot odds) to chaal/raise/pack/show, occasionally bluffs; easy is cautious-random but never absurd (e.g. doesn't pack a Trail). Bots must not peek at cards while blind. Result flags: folded when the learner packs; bigPot when |net| ≥ 8; closeFinish when a show was decided by high card or kicker; perfect when winning with a Trail; tags like 'trail', 'pure-sequence', 'blind-win' (won without seeing). Content: order 80, featured true, hook in the spirit of 'The game every Indian family plays at Diwali'. Mention chaal, boot, blind, seen, pack, show, trail, pure sequence in the glossary.
