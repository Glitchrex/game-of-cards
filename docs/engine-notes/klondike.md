# Engine notes: Klondike Solitaire

Single seat 0 (no opponent; currentPlayer is 0 until over). Draw-1, unlimited redeals. State: stock, waste, 7 tableau piles each with faceDown and faceUp arrays, 4 foundations by suit, move count, history for flags. Moves: {type:'draw'} (stock → waste), {type:'recycle'} (waste → stock when stock is empty), {type:'move', from: {kind:'waste'} | {kind:'tableau', pile, index /* index into faceUp where the moved run starts */} | {kind:'foundation', suit}, to: {kind:'tableau', pile} | {kind:'foundation'}}, {type:'resign'}. Rules: tableau builds down in alternating colours; only a King (or a run starting with a King) to an empty pile; foundations build up by suit from Ace; only single cards to a foundation; foundation → tableau allowed; the top face-down card flips automatically when exposed. legalMoves should list every legal move but avoid pointless ones? — list all legal moves including resign (resign always legal), the UI will highlight. checkMove reasons e.g. 'A red 7 must go on a black 8.', 'Only a King can go into an empty column.', 'Foundations are built up in one suit, starting with the Ace.'. Export helpers: autoFoundationMoves(state) (safe auto-moves for the UI 'Auto-finish' button), isWinnable heuristics NOT needed. Betting: Vegas-style per docs/RULES_DECISIONS.md: humanNetUnits = 5 × foundationCards / 52 − 1; outcome win if all 52 are home or net > 0, else loss. Bots (for simulation and the coach): normal = a good heuristic solver (prefer moves that flip face-down cards, move Aces/2s home, avoid emptying a column without a King to fill it, avoid pointless back-and-forth; detect no-progress cycles and resign after a full stock pass without progress); easy = random reasonable moves with a no-progress resign rule. Every simulated game MUST terminate (the harness maxMoves can be raised, but the bot must resign deterministically when stuck). Report the normal bot's win rate. coach(): suggest the best move found by the normal heuristic with a plain 'why'. Flags: perfect when cleared; comeback when cleared after ≥ 3 recycles; luckyLastCard when the last card to go home was the last face-down card exposed? (define something honest); bigPot when net ≥ 3. Content: order 100, featured true. Teach tableau, foundation, stock, waste, alternating colours, building down/up, empty column = King.
