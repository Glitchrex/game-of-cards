# Engine notes: Baccarat (Punto Banco)

Seats: 0 = learner (bettor), 1 = dealer. Phase 'bet': learner {type:'bet', on:'player'|'banker'|'tie'}. Then the dealer's forced {type:'deal'} moves deal ONE CARD per move in the correct order (Player, Banker, Player, Banker, then the third cards per the tableau) so the UI can animate it. Hand value = sum mod 10 (A=1, 2–9 face value, 10/J/Q/K = 0). Naturals 8/9 stop the deal. Player draws on 0–5, stands on 6–7. If Player stood, Banker draws on 0–5 and stands on 6–7. If Player drew a third card, Banker follows the standard table: Banker 0–2 draws; 3 draws unless Player's third card is 8; 4 draws if it is 2–7; 5 draws if 4–7; 6 draws if 6–7; 7 stands. Export the tableau as a pure function with a test for EVERY cell (banker total 0–7 × player third card none/0–9). Payouts: Player win +1, Banker win +0.95, Tie bet win +8; Player/Banker bets push (0) on a tie; losses −1; maxLossUnits 1. Coach: explain which bet has the lowest house edge (Banker ≈ 1.06%, Player ≈ 1.24%, Tie ≈ 14.4%) in plain words and that the drawing is automatic. Bots for simulation: normal bets Banker; easy random. Flags: perfect for winning with a natural 9; luckyLastCard when the winning side's third card turned the result; closeFinish when totals differ by 1; tags 'natural', 'tie'. Simulation also checks empirical Banker/Player/Tie frequencies over ≥ 50,000 coups are within tolerance of the known values (≈ 45.86% / 44.62% / 9.52%). Content: order 60.
