# Decisions log

Ambiguous product/technical choices, resolved toward the most standard, beginner-friendly
option. Game-rule variants live in `docs/RULES_DECISIONS.md`.

| ID | Decision | Why |
| --- | --- | --- |
| D-01 | **Next.js 16 + React 19 + Tailwind v4 + `motion`** (Framer Motion's current package name). | Latest stable versions at build time; `motion/react` is the Framer Motion API. |
| D-02 | **Drizzle ORM** with **libsql** (SQLite) locally and the `postgres` driver when `DATABASE_URL` starts with `postgres`. Two schema files with identical shape; one repository layer. Postgres path tested with PGlite. | Drizzle needs no binary engine download (works offline / behind proxies); SQLite file means zero setup. |
| D-03 | Migrations are applied **lazily on the first DB connection** (and by `npm run db:migrate`, which `predev` runs). | `npm install && npm run dev` must work on a fresh clone with only `.env` copied. |
| D-04 | **Escrow betting**: the shell takes `stake × maxLossUnits` from the wallet before the deal and, at the end, credits back `escrow + net × stake` (debiting any extra for doubles/splits, which are only allowed when affordable). | One uniform, cheat-proof settlement path for very different games (casino bets, pot games, points rummy, Vegas solitaire). |
| D-05 | **One deal/hand = one game** for Hearts, Spades, Teen Patti, Hold'em, Rummy. | Keeps a game under ~5 minutes for beginners; full-match rules are explained in Variants. |
| D-06 | Sound is **muted on first load**; the header toggle unmutes. Sounds are synthesized with WebAudio (no audio files) and the `AudioContext` is only created after a user gesture. | Satisfies autoplay policies and "muted by default until the user interacts". |
| D-07 | Tier is **derived** (a game is Tier 1 iff `src/games/<slug>/index.ts` exists). Registries are generated by `scripts/gen-registry.ts`. | Upgrading a Tier 2 game never touches its content file or any shared file. |
| D-08 | Italian-deck games (Scopa, Briscola) are taught with the **40-card French-suited** equivalent (remove 8, 9, 10; J/Q/K play the roles of Fante/Cavallo/Re). | Our card renderer is French-suited; this is how most people outside Italy play them. Noted in each game's Variants. |
| D-09 | Personas are original characters with SVG avatars built from simple shapes (no images). | Original art, tiny payload, no licensing questions. |
| D-10 | One vote per browser = random `voterToken` in localStorage **plus** a server-side `UNIQUE(post_id, voter_token)` constraint; votes toggle. IPs are stored only as salted SHA-256 hashes. | Matches the brief without accounts; avoids storing raw IPs. |
| D-11 | Rate limiting is an **in-memory sliding window per IP** (per server instance), capped at 10k tracked keys; IPv6 clients are bucketed per /64; the client IP is read `TRUSTED_PROXY_HOPS` entries from the right of `X-Forwarded-For`. Failed admin logins are limited to 10/min/IP. | No extra infrastructure; documented as a limitation for multi-instance deployments. |
| D-12 | Admin auth = password from `ADMIN_PASSWORD` → HMAC-signed, httpOnly, SameSite=Strict cookie (8 h). Admin mutations also require a same-origin request (`Origin` / `Sec-Fetch-Site`). Admin is disabled when the variable is empty, and in production when it still equals the `.env.example` value. | Simple and safe for a single-admin hobby site. |
| D-13 | Honeypot hits return a normal-looking success but store nothing. | Bots learn nothing from the response. |
| D-14 | i18n: UI strings live in `src/lib/i18n/en.ts` and are read through `t()`; game content is English-only for now (a `hi` content folder can be added later). | "Structure strings so Hindi can be added later". |
| D-15 | Deterministic E2E: play pages accept `?seed=<n>` (and `?difficulty=`) so tests can force a winning or losing deal. Seeds are ordinary inputs; they don't let anyone cheat anything real because Jeet is pretend. | Reliable win/loss Playwright tests. |
| D-16 | DB timestamps are stored as ISO-8601 UTC text in both dialects; SQLite runs through one connection guarded by a lock; vote and comment counts are recounted inside the same transaction. | Identical behaviour on SQLite and Postgres; counts can never drift. |
| D-17 | Malformed or unknown `:id` route params return 404 (not 400); non-JSON bodies 415; bodies over 32 KB 413. | One "not found" branch in the UI; defensive limits. |
| D-18 | Title/roast selection: score = sum of condition weights (firstWin 100, streak5 60, game-specific 40, other specific conditions 30, generic 0); sample among entries within 10 points of the best; the previous line is always excluded. Tips rotate through the game's list. A push gets neither a title nor a roast. | Context-aware, varied, never back-to-back. |
| D-19 | On phones the floating Feedback pill is hidden on `/games/*/play` and `/try` so it can't cover the action bar; feedback stays reachable from the header menu. | The brief wants feedback everywhere *and* a clean mobile table. |
